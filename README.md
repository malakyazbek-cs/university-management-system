# University Management System

A PHP and MySQL web application developed as a university coursework project to manage student records, faculty information, and basic administrative tasks.

> **A look back at where I started:** This project was developed as part of a university assignment based on the concepts we learned in class. I wrote the code manually, without using AI tools, applying my own understanding of PHP, MySQL, and web development at the time. Looking back at it today, with the knowledge and experience I have gained since then, the project feels relatively simple. However, it represents an important stage in my learning journey and reminds me of the progress I have made as a developer.

## Introduction

The University Management System is a simple web application designed to organize student and faculty information. It includes separate pages for administrative tasks and student access, with PHP handling the application logic and MySQL storing the data.

The main goal was to apply the programming and database concepts learned during university coursework in a practical project.

## Technologies Used

- **PHP** — Server-side programming
- **MySQL** — Database management
- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **XAMPP** — Local development environment
- **Visual Studio Code** — Code editor

## Features

- Administrator login
- Student login
- Student record management
- Faculty registration and management
- View student and faculty details
- Update and delete records
- MySQL database integration

## What I Learned

- Writing PHP code to build dynamic web pages.
- Connecting a web application to a MySQL database.
- Performing basic database operations: Create, Read, Update, and Delete (CRUD).
- Creating and processing HTML forms.
- Implementing basic login functionality.
- Organizing a multi-page web application.
- Applying concepts learned in class to a practical assignment.
- Debugging problems and understanding how different parts of a web application work together.

## Future Improvements

Although this project fulfilled its original coursework purpose, looking at it with my current knowledge, I can identify several ways it could be improved:

- **Security:** Hash passwords, use prepared SQL statements, and strengthen session management.
- **Code organization:** Separate database connections, application logic, and reusable components instead of repeating code across pages.
- **Validation and error handling:** Validate user input on the server, display helpful error messages, and handle database errors properly.
- **User interface:** Improve the layout, navigation, accessibility, and responsiveness for mobile devices.
- **Search and filtering:** Allow administrators to search, filter, and sort student and faculty records.
- **Additional functionality:** Add course registration, attendance tracking, grade management, and academic schedules.

## How to Run the Project

### Prerequisites

- XAMPP installed.
- A web browser.
- The project files and required database tables.

### Installation Steps

1. Download or clone this repository.
2. Place the project folder inside XAMPP's `htdocs` directory.
3. Start Apache and MySQL from the XAMPP Control Panel.
4. Open `http://localhost/phpmyadmin`.
5. Create the database required by the project and import the provided SQL file.
6. Check the database connection settings in the PHP files.
7. Open the application in your browser.
